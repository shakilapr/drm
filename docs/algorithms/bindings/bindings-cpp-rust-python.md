## Data Structures

```cpp
// bindings/cpp/include/drm/drm.hpp — header-only
template <class T> // T = generated byte-backed type (canon-codec accessors, no struct cast)
class [[nodiscard]] Borrow { // OWNING ACCESSOR — no separate view type, no pointer/span escape
public:
 float speed() const noexcept; // generated per-field accessors decode bytes in place (I-B2)
 // ... one accessor per schema field
 Borrow(Borrow&& o) noexcept
 : view_(o.view_), chan_(std::exchange(o.chan_, nullptr)) { o.view_.token = 0; } // moved-from invalid
 Borrow(const Borrow&) = delete;
 Borrow& operator=(const Borrow&) = delete;
 Borrow& operator=(Borrow&&) = delete;
 ~Borrow() noexcept { if (view_.token) drm_borrow_release(chan_, view_.token); } // I-B1: every path
private:
 drm_borrow_view view_{}; // caller-owned view/token (c-abi-surface.md)
 drm_consumer* chan_{nullptr};
};
// No .view() / .data() / .span(): nothing returns a pointer into the slot.
// Owned reads: drm::control::target::copy_latest() -> std::optional<OwnedTarget>
// (application-owned decode; retain freely) — architecture §Application Code Experience.
```

```rust
// bindings/rust/crates/drm — safe SDK
use core::marker::PhantomData;

pub struct BorrowGuard<'c> {
 token: u64,
 chan: &'c Channel,
 // Encodes !Send + !Sync: the borrower thread owns its consumer record (I-B8);
 // without this field the auto-traits would derive the opposite of the contract.
 _not_send_sync: PhantomData<*mut ()>,
}
impl<'c> BorrowGuard<'c> {
 pub fn bytes(&self) -> &[u8] { /* lifetime tied to &self ⇒ cannot outlive guard (I-B4) */ }
}
impl Drop for BorrowGuard<'_> { fn drop(&mut self) { drm_borrow_release(self.chan, self.token); } }

// Owned reads: Target::copy_latest() -> Result<OwnedTarget, Error> (owned; retain freely),
// Target::copy_next() -> Result<OwnedTarget | Gap{missed} | None, Error>.
```

```python
# bindings/python — PyO3 native core + pure facade; OWNED READS ONLY (no zero-copy API)
class Topic: # one consumer endpoint + native lock (I-B10); more concurrency ⇒ more Topics
 def latest(self) -> Copy | None: ... # acquire → copy → release INSIDE the call (I-B5); None on empty
 def next(self) -> Copy | None: ... # None when caught up; GapError on lapped read (I-C2)

class Copy: # application-owned memory; retain freely
 def bytes(self) -> bytes: ...
 def numpy(self) -> "np.ndarray": ... # NumPy-owned array; never a shared-memory view

# No borrow_latest/borrow_next/BorrowView/buffer(): Python's buffer protocol gives
# derived memoryviews an independent lifetime that cannot be revoked at scope exit
# (architecture §Core Language Ecosystem — Python ownership rule).
```

## Invariants

- **I-B1 CppEveryPathRelease**: destructor releases on normal exit, early return, exception propagation; a moved-from object (`token == 0`) releases nothing ⇒ no double release. Test: Catch2 unwinding + move suite.
- **I-B2 CppByteBacked**: generated C++ types decode canonical bytes through accessors; no `reinterpret_cast<T*>` of shared memory. Test: `cpp_byte_backed_view` (golden bytes via accessors).
- **I-B3 CppTwoLayer**: node facade (`.drm/gen/cpp/nodes/<name>.hpp`) declares only manifest topics and is the ONLY generated layer with endpoint operations; the shared types layer (`.drm/gen/cpp/types/...`) contains types, byte-backed accessors, owned types, and encode/decode helpers — never open/publish/subscribe. Test: compile-fail fixtures + generated-layer surface lint.
- **I-B4 RustSafeNoUAF**: no safe program can read payload after guard drop (lifetime-bound reference), and guards are genuinely `!Send + !Sync` via `PhantomData<*mut ()>`. Test: trybuild set — post-drop use, `thread::spawn(move guard)`, `scope` share of `&guard` all fail to compile.
- **I-B5 PythonOwnedOnly**: no Python-visible object references a DRM payload slot; the buffer protocol is not implemented; acquire→copy→release completes before control returns to Python. Test: memory-identity check + hazard-word probe (`protected[id] == NONE` after every call).
- **I-B6 PythonHazardFree**: GC pauses, exceptions, or reference cycles cannot pin a hazard slot beyond the call; copies (`bytes`/`numpy`) retain freely. Test: forced-GC suite + slot-free assertion.
- **I-B7 ContractError**: undeclared topic access raises `ContractError` at first use. Test: negative suite.
- **I-B8 ConsumerLeasePerBorrower**: activation reserves `borrowers` records per declared consume endpoint (manifest; default 1; records also carry required-sequential `ack_seq`); each borrower claims one via `drm_consumer_open`; none free ⇒ `Busy`; two borrowers never share a hazard slot. Test: `consumer_lease` (claim N, N+1 ⇒ `Busy`).
- **I-B9 AppLogNonblocking** (REQ-BIND-023): `drm.log(level, message)` writes into the observability ring through `drm_log(level, msg_ptr, len)` — one bounded `try_push`, best-effort drop, no wait and no data-plane access; exposed in all four bindings. Phase 2 upgrades call sites to compiled trace IDs. Test: `app_log_nonblocking` (operation-count assertion) + drop counter + per-binding smoke.
- **I-B10 PythonThreading**: `Topic` is `Send + Sync` (PyO3); calls on one `Topic` serialize on a native lock (cursor coherence); free-threaded and GIL CPython builds pass the full suite; the native core has no GIL dependency. Test: free-threaded + GIL build matrix.

## Functions

```rust
// Python facade core (PyO3)
fn latest(&self) -> PyResult<Option<Copy>> {
 let _g = self.endpoint_lock.lock().unwrap_or_else(Poisoned::into_inner); // I-B10; poison unreachable under fail-stop
 let mut buf = vec![0u8; self.max_len()]; // binding-layer alloc; native core stays zero-alloc (I-C9)
 let Some(len) = self.core.copy_latest(&mut buf)? else { return Ok(None) }; // empty channel
 buf.truncate(len);
 Ok(Some(Copy::from_owned(buf))) // Python-owned; hazard already cleared (I-B5)
}
```

*Generated two-layer output:*

```text
.drm/gen/cpp/control/target/target.hpp   # schema, byte-backed accessors, owned type, encode/decode
.drm/gen/cpp/nodes/controller.hpp         # namespace drm::node::controller — only manifest topics
.drm/gen/rust/control/target/target.rs    # `pub struct ControlTarget` + `encode`/`decode`/`SAMPLE_MAX`
.drm/gen/rust/nodes/controller.rs         # pub mod node_controller — capability facade
```

The Rust topic module derives `Clone`, `Debug` and `PartialEq` and implements `Default`
**explicitly, never by derive**: `std` implements `Default` only for arrays of 0..=32
elements, so a derived impl cannot compile for the `[u8; N]` fields that a `string[N]`,
`bytes[<=N]` or fixed-array declaration produces (rust-lang/rust#61415). Guarded by
`codegen_all::gen_rust_bounded_topic_compiles_and_round_trips`.

The types layer is shared by every node using the topic (codegen-invalidation.md); the facade layer is node-scoped and sole owner of endpoint operations. The raw C ABI stays below both; open-time authorization still rejects undeclared topics — static languages get the restriction at compile time, dynamic languages at first use, and neither performs per-message checks.

## Protocols

*Python owned read:*

1. `topic.latest()` / `topic.next()` → lease the `Topic`'s consumer endpoint under its native lock.
2. Core acquire (hazard) → copy into fresh Python-owned memory → release hazard.
3. Return the owned object (`None` on empty/caught-up; `GapError` on gap); no DRM reference survives the call (I-B5/I-B6).
4. Workloads that cannot tolerate the copy call a native (Rust/C++) extension over DRM's zero-copy paths (architecture §Core Language Ecosystem).

*Per-borrower lease (I-B8):* the manifest's `borrowers = N` reserves N records/hazard words at activation; borrower threads claim records at endpoint open; exhausted ⇒ `Busy`. Per topic, `H = Σ declared borrowers + diagnostic-consumer range` feeds the pool drop-free bound (payload-pool.md I-P5).

*Interop matrix (all cells, Phase 20–22 gates):* publisher/consumer in every language pair over fixed + variable topics on golden fixtures — byte identity (canon-codec I1).

## Edge Cases & Errors

| Case | Result |
|---|---|
| C++ borrow of empty channel | returns `std::optional<Borrow<T>>` empty |
| C++ moved-from `Borrow` destructs | no release (`token == 0`) — no double free (I-B1) |
| C++ retain payload beyond scope | impossible without copy: no accessor yields a pointer (I-B3 surface lint) |
| Rust double-borrow of exclusive cursor | compile error (trybuild) |
| Rust guard moved/shared across threads | compile error (trybuild, I-B4) |
| Python undeclared topic | `ContractError` (I-B7) |
| Python `latest()` on empty channel | `None` — no exception (I-B5) |
| Python `next()` caught up / lapped | `None` / `GapError` (I-C2) |
| Python GC/exception during `latest()` | slot released before return (I-B6) |
| Copies retained arbitrarily long | safe — application-owned memory (I-B5) |
| More `Topic`s than declared borrowers | `Busy` at consumer open (I-B8) |
| Two threads on one `Topic` | serialized on the native lock; cursor coherent (I-B10) |
| After `fork()` in the child | inherited `Topic`s/guards invalid; child must `exec` or reattach (architecture §Process Lifecycle) |
| C++ exception mid-scope | destructor releases (I-B1) |
| Cross-language Gap | typed in each language (Rust `Gap{missed}`, Python `GapError`, C++ `DRM_ERR_GAP` + `out_missed`) |
