## Data Structures

```cpp
// bindings/cpp/include/drm/drm.hpp — header-only
template <class T> // T = generated byte-backed view type
class [[nodiscard]] Borrow {
public:
 Borrow(Borrow&& o) noexcept
 : view_(o.view_), chan_(std::exchange(o.chan_, nullptr)) { o.view_.token = 0; } // moved-from invalid
 Borrow& operator=(Borrow&&) = delete; // no reassignment of protection
 ~Borrow() noexcept { if (view_.token) drm_borrow_release(chan_, view_.token); } // I-B1: release on EVERY path
 // Byte-backed access: each accessor decodes its canonical offset (canon-codec), NOT a struct cast.
 const T view() const noexcept;
private:
 drm_borrow_view view_{}; // caller-owned view/token (c-abi-surface.md)
 drm_consumer* chan_{nullptr};
};
```

```rust
// bindings/rust/crates/drm — safe SDK
pub struct BorrowGuard<'c> { token: u64, chan: &'c Channel } // caller-owned token (c-abi-surface.md)
impl<'c> BorrowGuard<'c> {
 pub fn bytes(&self) -> &[u8] { /* lifetime tied to &self ⇒ cannot outlive guard */ }
}
impl Drop for BorrowGuard<'_> { fn drop(&mut self) { drm_borrow_release(self.chan, self.token); } }
// !Send + !Sync: each concurrent borrower thread must open its own consumer id (I-B8).
```

## Invariants

- **I-B1 CppEveryPathRelease**: destructor releases on normal exit, early return, exception propagation; a moved-from object (`h_ == 0`) releases nothing ⇒ no double release. Test: Catch2 unwinding + move suite.
- **I-B2 CppByteBacked**: generated C++ types decode canonical bytes through accessors; no `reinterpret_cast<T*>` of shared memory. Test: `cpp_byte_backed_view` (golden bytes via accessors).
- **I-B3 CppNodeScoped**: generated per-node header declares only manifest topics; undeclared publish is a compile error. Test: compile-fail fixtures.
- **I-B4 RustSafeNoUAF**: no safe program can read payload after guard drop (lifetime-bound reference). Test: trybuild set.
- **I-B5 PythonOwnedDefault**: `latest()` and `numpy()` never return DRM-shared memory (deep copy into owned/NumPy-owned buffer). Test: memory-identity check.
- **I-B6 PythonScopePinned**: forced GC / exceptions inside `with` cannot pin a hazard slot beyond scope; `buffer()` after exit is invalid; `numpy()`/`bytes()` are copies and safe to retain. Test: forced-GC suite + slot-free assertion.
- **I-B7 ContractError**: undeclared topic access raises `ContractError` at first use. Test: negative suite.
- **I-B8 ConsumerIdPerBorrower**: each concurrently borrowing thread owns a distinct consumer/hazard id; concurrent borrows from one process never share a hazard slot. Test: `consumer_id_alloc`.
- **I-B9 AppLogNonblocking**: `drm.log(level, message)` writes into the observability ring through `drm_log(level, msg_ptr, len)` — one bounded `try_push`, best-effort drop, no wait and no data-plane access; exposed in all four bindings. Phase 2 upgrades call sites to compiled trace IDs. Test: `app_log_nonblocking` (operation-count assertion) + drop counter + per-binding smoke.

## Functions

```rust
// Python facade core (PyO3)
fn borrow_latest_enter(&mut self) -> PyResult<BorrowView> {
 let v = self.core.borrow_latest()?; // view + token; one outstanding (hazard-protocol.md)
 PyResult::Ok(BorrowView { view: v, valid: true })
}
fn borrow_latest_exit(&mut self, v: BorrowView) {
 self.core.release_token(v.view.token); v.valid = false; // scope exit ⇒ slot freed (I-B6)
}
fn BorrowView_numpy(&self) -> PyResult<PyObject> {
 // I-B5: always an owned array; copies out of shared memory, never a view.
 let owned = self.buffer().to_vec();
 numpy_from_owned(owned)
}
```

*Generated node API (static languages):* codegen emits `namespace drm::node::<name>` (C++) / `pub mod node_<name>` (Rust) containing ONLY declared topics — the manifest is the capability surface (c-abi-surface.md §Protocols step 4 for raw ABI parity). Generated payload types are byte-backed views with named codec accessors (I-B2): C++ exposes `target->speed()`, never a public data member or `reinterpret_cast<T*>`; Rust exposes lifetime-safe accessor methods. Views are shared across nodes per codegen-invalidation.md.

## Protocols

*Python borrow scope:*

1. `with topic.borrow_latest() as frame:` → acquire (hazard protocol).
2. `frame.buffer()` → borrowed memoryview; NaN-free in-scope use only.
3. `frame.numpy()` / `frame.bytes()` → owned copies, safe to retain beyond the block.
4. Block exit (normal or exception, GC interposed) → hazard cleared; `frame.buffer()` afterwards raises `BorrowExpired`.

*Per-borrower consumer identity (I-B8):* a process with N concurrent borrower threads opens N consumer ids (hazard slots); generated static bindings enforce this by tying a guard to the channel/thread that opened it.

*Interop matrix (all cells, Phase 20–22 gates):* publisher/consumer in every language pair over fixed + variable topics on golden fixtures — byte identity (canon-codec I1).

## Edge Cases & Errors

| Case | Result |
|---|---|
| C++ borrow of empty channel | returns `std::optional<Borrow<T>>` empty |
| C++ moved-from `Borrow` destructs | no release (`h_ == 0`) — no double free (I-B1) |
| Rust double-borrow of exclusive cursor | compile error (trybuild) |
| Python undeclared topic | `ContractError` (I-B7) |
| Python GC during borrow | slot pinned only until block exit (I-B6) |
| `buffer()` after scope | `BorrowExpired` |
| `numpy()` retained after scope | safe — it is an owned copy (I-B5) |
| Two threads borrowing one channel | each must hold its own consumer id (I-B8) |
| C++ exception mid-scope | destructor releases (I-B1) |
| Cross-language Gap | typed in each language (Rust `Gap{missed}`, Python `GapError`, C++ status) |
