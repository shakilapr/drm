## Invariants

- **I-QAL1 CoverageComplete**: `xtask audit-traceability --matrix` reports 100% with each row carrying an evidence class — test oracle, positive case, negative/adversarial case, boundary case, fault injection where applicable, result artifact hash, platform. Link existence alone never closes a row. High-risk invariants (ordering, integrity, isolation, heap) are additionally mutation-audited: a seeded defect (e.g. `<=` → `<`, removed CRC check, inverted epoch comparison, removed queue-full handling) must make the linked test fail. Test: matrix artifact + CI job + mutation ledger.
- **I-QAL2 SoakClean**: three gates, all zero corruption/deadlock (anomaly counters all zero): (a) regression soak — three consecutive clean 24 h runs over rotating topologies; (b) continuous aging — one uninterrupted ≥ 72 h run (no restart resets state: counters, epochs, pools, timers accumulate); (c) accelerated boundary suite — sequence/epoch wrap, pool-exhaustion cycling, reconnect cycling, timer/clock boundaries. Soak demonstrates regression stability, not statistical MTBF; duration-based reliability claims must derive from an explicit target (zero-failure bound at 95% confidence: T ≥ 2.996·M test-hours). Test: soak ledger (three ledgers).
- **I-QAL3 Reproducible**: two independent clean runners per supported platform produce bit-identical declared primary artifacts (workspace crates + `drm.h`); the artifact list is declared, never "everything in target/". Locked toolchain, `--locked`, `SOURCE_DATE_EPOCH`, path/env normalization; mismatch ⇒ binary diff (diffoscope) before gate re-run. Test: build-repro job (≥ 6 builds for three platforms).
- **I-QAL4 MatrixClosed**: every declared-supported cell passes; undeclared cells absent from report. Test: conformance harness.
- **I-QAL5 BenchInvariants**: load suite asserts zero allocation, bounded operation counts, and reports latency without treating estimates as proof. Test: bench CI.
- **I-QAL6 DefectLedger**: P0 = 0; P1 all closed or waived with record. Test: ledger audit.
- **I-QAL7 FuzzResolved**: 0 unresolved reproducible fuzz crashes/hangs and 0 unresolved sanitizer findings; regression corpus replay 100% pass; minimum campaign budget reached; corpus + deterministic failing seeds persisted. "Triaged" is a project state, not a passing state. Test: fuzz/sanitizer ledger.
- **I-QAL8 CriticalPathCoverage**: the declared critical paths — runtime ring history, overflow policies, hazard protocol, exhaustion/reclamation, and the router transports — each resolve to at least one linked test that exercises an oracle, a boundary, and a negative/adversarial branch. A path with no resolved linked test, or a linked test that no longer exists, is a gap; the gate counts resolved paths, never line count. Test: `xtask/src/coverage.rs` (`CRIT_COVERAGE`) + `docs/spec/coverage-policy.md`.
- **I-QAL9 MutationSample**: a seeded defect on a hazard/ring critical predicate (`<=`→`<`, inverted epoch comparison, removed queue-full handling, removed CRC/validation check) is detected by the linked oracle; an undetected seeded defect blocks the gate and the linked test is strengthened before close. The sample is a fixed-seed, fixed-size subset (documented rate), not an exhaustive mutation run. Test: `xtask/src/coverage.rs` mutation-sample self-check.

## Functions

```rust
fn qualify() -> QualificationReport {
 let matrix = traceability::matrix(registry, code_facts, test_results); // I-QAL1
 let soak = soak::summary(all_runs);
 let cells = conformance::full_matrix();
 let fs = fuzz_sanitizer::results();
 let repro = build_repro::verify_per_platform(two_runners_each); // I-QAL3
 let docs = docs_examples::run_headless();
 let coverage = coverage::critical_paths(root); // I-QAL8
 let mutation = coverage::mutation_sample(); // I-QAL9
 let inventory = inventory::freeze_candidates(root); // REQ-QAL-021
 let defects = ledger::audit();
 report(matrix, soak, cells, fs, repro, docs, coverage, mutation, inventory, defects) // gate = all invariants green
}
```

## Protocols

*Traceability closure:*

1. `audit-traceability --matrix` → gap list (REQs missing impl/test/result/evidence class).
2. Per gap: owner claims → implement/test/link (row must state oracle + positive + negative + boundary + fault-injection evidence) → same-PR registry sync.
3. High-risk invariants: mutation audit — seed each listed defect class, confirm the linked test fails, record in the mutation ledger.
4. Repeat until 100%; matrix + mutation artifacts archived.

*Soak protocol (three ledgers →M23):*

1. Regression soak: daily 24 h runs, rotating topologies (single-machine, two-machine sim, physical pair). Any anomaly ⇒ triage → fix → restart (counter resets only on clean full run). Gate: three consecutive clean runs.
2. Continuous aging: one uninterrupted ≥ 72 h run — no process restart, so state accumulation (counters, epochs, pools, timer drift) is exercised; restart-cycling between regression runs must not substitute for it.
3. Accelerated boundary suite: forced epoch/sequence wrap, pool-exhaustion cycling, reconnect cycling, clock-step/timer boundary matrix.
4. Classification: gates (1)–(3) demonstrate regression stability and aging robustness; statistical reliability claims require an explicit target and test hours derived from it (zero-failure exponential model at 95%: T ≥ 2.996·M).

*Build reproducibility:*

1. Pinned toolchain (rust-toolchain.toml), `--locked`, `SOURCE_DATE_EPOCH`, path remapping and environment normalization declared per platform.
2. For each supported platform (e.g. ubuntu-x86_64, ubuntu-aarch64, windows-x86_64): build on two isolated clean runners; hash the declared primary artifacts (`drm.h` + workspace crate outputs) and compare per platform.
3. Differences ⇒ locate with binary diff (diffoscope), fix the nondeterminism source (timestamps, paths, env, linker variation), re-verify.

## Soak Escalation Harness (M18W4)

`REQ-QAL-013`, `REQ-QAL-014`; refines the soak protocol above. The harness is
`cargo xtask soak` (`xtask/src/soak.rs`); the ledger format is
[docs/spec/soak-ledger.md](../../spec/soak-ledger.md).

```rust
pub enum Topology { SingleMachine, TwoMachineSim, PhysicalPair } // rotation order
pub struct SoakRun {
 topology: Topology, hours: u64, iterations: u64,
 anomalies: u64, clean: bool, finished_unix_s: u64,
}
pub struct SoakLedger { runs: Vec<SoakRun> } // I-QAL2 evidence ledger
```

- **Escalation**: daily 24 h runs (`xtask soak --duration 24`), one per topology
  in round-robin order (`Topology::next_after(run_count)`), so consecutive runs
  exercise single-machine, two-machine simulation, then physical-pair links.
  `--topology` pins one explicitly for a targeted re-run.
- **Anomaly ⇒ triage**: any failing suite iteration is recorded as a
  non-clean run (anomaly counter) and the harness exits nonzero; the operator
  fixes the defect and restarts. Counters reset only on a clean full run.
- **Three-consecutive-clean rule** (`I-QAL2`): the regression gate holds iff the
  trailing clean-run streak is ≥ [`REQUIRED_CLEAN_RUNS`] (3). An anomaly resets
  the streak; the clock restarts only on an anomaly.
- **Dashboard** (`REQ-QAL-014`): `xtask soak --dashboard` renders the ledger as
  a per-run trend (topology, iterations, anomaly counter, clean flag, trailing
  streak, gate verdict). The ledger is the committed evidence artifact.

## Fault Injection Campaigns (M23W2)

`REQ-QAL-010`, `REQ-QAL-015`, `REQ-QAL-016`; harness is `cargo xtask fault`
(`xtask/src/fault.rs`); detail: [fault-injection.md](../../spec/fault-injection.md).

```rust
pub enum FaultCampaign { PublisherCrash, ExhaustionBurst, SubscriberKill, SerialBomb, LinkStorm }
pub struct Scenario { seed: u64, steps: u64 } // seeded xorshift64 fault schedule
pub struct Replay { published: u64, dropped: u64, reclaimed: u64, digest: u64 }
```

- **Campaigns** (`FAULT_CAMPAIGNS = 5/5`): publisher-crash (mid-publish
  teardown), exhaustion-burst (pool exhaustion under
  [exhaustion-reclamation.md](../runtime/exhaustion-reclamation.md) policies),
  subscriber-kill (hazard-slot correctness under
  [hazard-protocol.md](../runtime/hazard-protocol.md)), serial-bomb (transport
  framing), and link-storm (router flapping). A red campaign fails the command
  (triage-first).
- **Determinism** (`REQ-QAL-016`): the seeded schedule and its digest are the
  reproduction key; the `PoolModel` replay mirrors the exhaustion/reclamation
  counters, so a failure replays from its recorded seed.
- **Soak harness (M23W2)**: `xtask soak --parallel 3 --memory-bound <mb>
  --report <path>` runs three parallel 24 h runs in isolated target dirs,
  samples peak RSS against the ceiling (I-MB9 included), and writes the
  auto-report; the ledger threshold band picks the zero-false-positive anomaly
  band (`REQ-QAL-017`).

## Perf Invariant Harness + Gate Packet (M23W4)

`REQ-QAL-011`, `REQ-QAL-012`, `REQ-QAL-018`, `REQ-QAL-019`; implements `I-QAL5`
and the `qualify()` packet assembly. Benches are the harness (`xtask` orchestrates
nothing new at runtime); the packet is `cargo xtask qualify`
(`xtask/src/qualify.rs`).

- **Bench invariants** (`I-QAL5`): the runtime, router, codec, and transport
  benches assert zero allocation and a bounded-time p99 ceiling *inside* the
  bench (the counting `GlobalAlloc` and the nearest-rank percentile helper live in
  `benches/common/mod.rs`); a violation aborts the bench with a non-zero exit.
  Budgets are fixed in [bench-methodology.md](../../spec/bench-methodology.md)
  and recorded in [bench-baseline.md](../../spec/bench-baseline.md). The
  exhaustion path (`publish_queue_full`) additionally checks its worst-case
  footprint against the declared budget ([memory-budget.md](../memory-budget.md)
  `I-MB1`). CI runs every bench as a required job.
- **Gate packet** (`qualify()`): assembles the whole-system packet — `I-QAL1`
  traceability matrix, `I-QAL2` fault/soak evidence, `I-QAL3` repro evidence,
  `I-QAL4` conformance closure, docs CI, and `I-QAL5` perf invariants — and
  fails (`--check`) while any leg is unmet. The conformance leg closes the
  declared OS×language×transport matrix: every declared cell is supported on the
  host or scheduled behind a named dependency, the gate-blocking same-language
  core is exactly 24 cells, and undeclared cells cannot appear (the manifest is
  the sole source). `cargo xtask qualify --json <path>` writes the packet.

*Coverage closure (I-QAL8/I-QAL9, M24W1):*

1. Enumerate the declared critical paths (ring history, overflow policies, hazard, exhaustion, transports) in `docs/spec/coverage-policy.md`; each path names its source owner, its `REQ` anchor, and its linked tests.
2. `cargo xtask qualify` resolves every critical path to an existing linked test; a path whose linked test is missing is a gap and fails `--check`.
3. Run the fixed-seed mutation sample on the hazard/ring predicates: each seeded defect must be detected by the linked oracle; an undetected defect blocks the gate.
4. New gap tests are added, never refactors (M24W1 risk cap); the coverage leg is unified into the qualification packet.

## Release Freeze & Pilot Deployment (M24W2)

`REQ-QAL-023`, `REQ-QAL-024`, `REQ-QAL-025`, `REQ-QAL-026`; the release
close-out wave. Harnesses: `cargo xtask freeze` (`xtask/src/freeze.rs`),
`cargo xtask pilot` (`xtask/src/pilot.rs`), `cargo xtask package`
(`xtask/src/packaging.rs`); detail: [api-freeze.md](../../spec/api-freeze.md),
[packaging.md](../../spec/packaging.md). The freeze executes the M24W1
inventory ([api-inventory.md](../../spec/api-inventory.md), `REQ-QAL-021`).

```rust
pub struct VersionLock { pub name: String, pub manifest: String, pub version: String }
pub struct ArtifactStamp { pub artifact: String, pub abi_version: u32, pub fingerprint: [u8; 16] }
pub struct FreezeReport {
 pub versions: Vec<VersionLock>, // every crate + binding at the locked release version
 pub frozen_surfaces: usize,     // freeze candidates re-resolved against their owners
 pub note_published: bool,       // docs/spec/api-freeze.md present
}
pub struct PilotEnv { pub router: bool, pub mcu: bool, pub studio: bool, pub stamp: ArtifactStamp }
pub struct RollbackDrill { pub deployed: bool, pub injected_fault: FaultCampaign, pub rolled_back: bool }
pub struct Bundle { pub name: String, pub kind: BundleKind, pub source: String, pub present: bool }
```

- **Version lock** (`REQ-QAL-023`): every workspace crate (`version.workspace`)
  and every binding manifest (Rust crate, Python `pyproject`/native crate,
  Studio `package.json`) is read from disk and must equal the locked release
  version; a divergent manifest fails the command. Lockstep versioning is the
  codebase §6.1 rule.
- **Frozen surfaces**: the M24W1 freeze candidates are re-resolved against their
  owners exactly as `inventory::verify` does; the freeze is append-only
  (I-A8) — a renamed or removed frozen symbol fails `cargo xtask freeze`.
- **Artifact stamping** (`REQ-QAL-023`, deployment-identity.md): every released
  artifact is stamped with its ABI version and its contract fingerprint computed
  from the declared inputs — `hash(ABI version, topic schemas, declared
  interfaces)` (`REQ-CORE-085`). The stamp is recomputed from the declared inputs
  so a drift between the stamp and the inputs is a gate failure.
- **Pilot environment** (`REQ-QAL-024`): the field environment is the real
  router + MCU binding + Studio UI surface, each verified present; the stamped
  deployment identity rides along and is re-checked (`PILOT_DEPLOYED = 1`).
- **Rollback drill** (`REQ-QAL-025`, EXP inside the pilot task): deploy ⇒ inject
  a seeded fault (a [`FaultCampaign`](../../spec/fault-injection.md)) ⇒ roll back.
  The drill passes iff the rollback restores the pre-deploy deployment identity
  and the frozen surface is unchanged — i.e. the fix lives behind the existing
  surface, never a new API.
- **Pilot packaging** (`REQ-QAL-026`): a release-package dry-run builds the
  declared bundle set — workspace crates, the C/C++ headers, the Rust SDK crate,
  the Python wheel source, and the Studio packages — and verifies each source
  resolves per codebase §2.3; the dry-run renders the bundle manifest that the
  real pilot bundles consume. `BUNDLES_VERIFIED = resolved/total`.

*Freeze protocol (M24W2):*

1. `cargo xtask freeze --check` → versions locked, frozen surfaces resolved,
   stamps consistent, freeze note published. `API_FROZEN = 1`.
2. `cargo xtask pilot --check` → field environment present, identity stamped,
   rollback drill clean. `PILOT_DEPLOYED = 1`.
3. `cargo xtask package --check` → bundle set resolved. `BUNDLES_VERIFIED`.
4. Pilot-only issues are fixed behind the frozen surface; a required API change
   reopens the freeze (new ABI bump) rather than silently drifting.
5. The freeze/pilot/package legs fold into the qualification packet
   (`cargo xtask qualify --check`); artifacts archived with the M24W2 gate.

## Edge Cases & Errors

| Case | Result |
|---|---|
| REQ deemed non-normative during drive | architecture edit + registry sync same PR (R1) — never silent row deletion |
| Soak anomaly at hour 23 | run restarts after fix (three consecutive clean runs rule) |
| Linked test passes but linked requirement untested by it | evidence-class audit rejects row; mutation audit required for high-risk |
| Seeded defect not caught by linked test | gate blocks; test strengthened before close |
| Fuzz crash labeled/triaged but unfixed | I-QAL7 still fails — resolution, not triage, gates |
| Repro hash diff from env leak | env normalization added; re-verify |
| Example broken by API change | docs-CI catches; fix in same PR |
| Waiver requested for P1 | recorded with rationale + approver; visible in report |
