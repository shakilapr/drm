## Invariants

- **I-QAL1 CoverageComplete**: `xtask audit-traceability --matrix` reports 100%; any gap row blocks the gate. Test: matrix artifact + CI job.
- **I-QAL2 SoakClean**: ≥ 72 h cumulative soak across mixed topologies with zero corruption/deadlock (anomaly counters all zero). Test: soak ledger.
- **I-QAL3 Reproducible**: two clean builds on different runners bit-identical (workspace crates + drm.h artifacts). Test: build-repro job.
- **I-QAL4 MatrixClosed**: every declared-supported cell passes; undeclared cells absent from report. Test: conformance harness.
- **I-QAL5 BenchInvariants**: benchmark suite asserts architecture invariants under load (zero-alloc steady state, bounded times). Test: bench CI.
- **I-QAL6 DefectLedger**: P0 = 0; P1 all closed or waived with record. Test: ledger audit.

## Functions

fn qualify() -> QualificationReport {
 let matrix = traceability::matrix(registry, code_facts, test_results); // I-QAL1
 let soak = soak::summary(all_runs);

## Protocols

*Traceability drive ():*

1. `audit-traceability --matrix` → gap list (REQs missing impl/test/result).
2. Per gap: owner claims → implement/test/link → same-PR registry sync.
3. Repeat until 100%; matrix artifact archived.

*Soak escalation protocol (→M23):*

1. Daily 24 h runs, rotating topologies (single-machine, two-machine sim, physical pair).
2. Any anomaly ⇒ triage → fix → soak restarts (counter resets only on clean full run).
3. Gate requires three consecutive clean 24 h runs.

*Build reproducibility:*

1. Pinned toolchain (rust-toolchain.toml), `--locked`, `SOURCE_DATE_EPOCH` normalized.
2. Build on ubuntu-x86_64 + ubuntu-aarch64 + windows; compare artifact hashes of `drm.h` + crate outputs (per-platform comparison).
3. Differences ⇒ fix nondeterminism source (timestamps, paths, env).

## Edge Cases & Errors

| Case | Result |
|---|---|
| REQ deemed non-normative during drive | architecture edit + registry sync same PR (R1) — never silent row deletion |
| Soak anomaly at hour 23 | run restarts after fix (three consecutive clean runs rule) |
| Repro hash diff from env leak | env normalization added; re-verify |
| Example broken by API change | docs-CI catches; fix in same PR |
| Waiver requested for P1 | recorded with rationale + approver; visible in report |
