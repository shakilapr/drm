}

## Invariants

- **I-ST1 SingleSemantics**: every mutation goes through the engine's parse→model→verify pipeline (workspace-model + verify-engine); Studio never validates independently. Test: mutation-parity test — same edits via CLI and Studio produce identical model renders.
- **I-ST2 GeneratedOnly**: `packages/studio-protocol` regenerated by `xtask gen-check`; hand edit ⇒ CI fail (R6). Test: gen-check.
- **I-ST3 PlaneSeparation**: no topic sample bytes ever travel in JSON-RPC; no commands in binary plane. Test: protocol audit fixture.
- **I-ST4 CapabilityModel**: renderer receives capability lists (allowed topics/actions), never raw machine/SHM access. Test: renderer-import lint (no Electron/Node built-ins per §3.5).
- **I-ST5 ExtensionBudgets**: extensions run in wasmtime with fuel + memory caps; budget exhaustion ⇒ deterministic termination, engine unaffected. Test: `ext_budget` fixtures.
- **I-ST6 EngineEditsDocuments**: GUI mutations preserve hand-written comments/whitespace/ordering where possible (document-preserving edits). Test: edit-preservation fixture.

## Functions

```rust
// drm-cli::studio --stdio host
fn serve_stdio(mut rx: impl Read, tx: impl Write) -> Result<(), Status> {
 for line in rx.json_lines() {
 let req: StudioRequest = parse(line)?;
 let resp = dispatch(req)?; // engine calls only — single-semantics rule (I-ST1)
 tx.write(resp.to_json_line())?;
 }
 Ok(())
}

fn dispatch(req: StudioRequest) -> Result<StudioResponse, Status> {
 match req {
 OpenWorkspace { path } => workspace_model::build(tree(path)).map(render), // I-D1 reuse
 ApplyEdit { edit } => {
 let model = load()?;
 let new = apply_edit_preserving(model, edit)?; // I-ST6
 verify::run(&new)?; // gate mutations (verify-engine)
 save_and_render(new)
 }
 Build { .. } => build_orchestration::build(..).map(render),
 Run { .. } => lifecycle::control(..).map(render),
 SubscribeTelemetry { .. } => diag::subscribe(..).map(render),
 }
}
```

## Protocols

*Edit flow (I-ST1/I-ST6):*

1. Studio sends `ApplyEdit` (declarative edit: add topic, assign publisher…).
2. Engine applies with document preservation, re-parses, re-verifies.
3. Response = new canonical model render (deterministic) + capability delta.
4. On verify failure: errors with check-IDs returned; workspace unchanged.

*Extension loading:*

1. Extension declares surface (subset of studio-extension-api).
2. Host instantiates in wasmtime with fuel/memory budgets (I-ST5).
3. Extension calls only exported API; engine state never shared.

## Edge Cases & Errors

| Case | Result |
|---|---|
| Malformed JSON-RPC line | error response, connection continues |
| Edit failing verify | full failure report (check-IDs + REQ citations); no partial apply |
| Extension fuel exhaustion | deterministic stop; engine unaffected (I-ST5) |
| Studio disconnect mid-build | build completes headless (engine-owns-state rule) |
| Two Studio instances | single in-flight build lock per workspace (build-orchestration §Edge Cases) |
