## Notes

- No architecture divergence: the slice implements pinned invariants
  (observability-plane I-OB1..I-OB7), so no ADR landed.
- The lock-free SPSC primitive lives in `drm-core::trace` (runtime) because
  codebase.md §2.2 confines `unsafe` to `drm-core`/`drm-ffi`; the `drm-trace`
  crate composes it safely and lands with the trace reader/merge.
- Live SHM attach for the tools is deferred to the diag session; without a
  running publisher they resolve deployment metadata and report `NotFound`
  (namespace scoping). The no-pin guarantee is proven in-process.
- MCU bring-up executes in CI (`mcu-cross.yml`); the authoring host lacks the
  pinned `arm-none-eabi` toolchain, so the local suite reports the skeleton and
  the CI job carries the hello-world build + zero-heap symbol audit.
