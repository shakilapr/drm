## Notes

- No architecture divergence: the slice implements pinned invariants
  (observability-plane I-OB2/3/4/5/7, record-replay I-RC1/2/3/5, serial-mcu
  I-SR2..I-SR6), so no ADR landed.
- `drm-record` is the ops-layer crate projected in codebase.md §2.1; it depends
  only on `drm-types` + `drm-core` (`#![forbid(unsafe_code)]`) and never touches
  DRM slots from the disk stage (`I-RC1`, `REQ-OPS-007`). Disk threads, MCAP
  framing, and replay land with M15W3/M15W4.
- The MCU subset is freestanding C11 verified two ways: the Arm cross-build in
  CI (`mcu-cross.yml`, both locked targets) and a host parity run of the same
  golden COBS/CRC vectors (`make host-test`), plus the zero-forbidden-heap
  symbol audit (`make host-audit`, `make audit`). The authoring host lacks the
  pinned `arm-none-eabi` toolchain, so the parity and audit legs execute with
  the host compiler.
- Aggregation is out-of-band only (`I-OB2`); `deadline_tick` counts exactly one
  miss per `Current → Late` transition and reports historical counts as
  observational (never a warranty).
