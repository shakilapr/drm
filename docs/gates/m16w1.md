## Notes

- No architecture divergence: the slice implements pinned invariants
  (rpc-actions I-RPC1/3/4/6/7/9/10); no ADR landed. `drm-rpc` is an ops crate
  (`#![forbid(unsafe_code)]`) depending only on `drm-types` + `drm-core`; it adds
  zero core ring semantics (I-RPC4) and composes the existing `Channel` only.
- M16W1 scope is unary request/response: the action phase machine, deterministic
  cancel-at-phase-boundary protocol, and the C ∈ 1..=16 dispatch fixture carry to
  M16W2/M16W3 per the week matrix. `apply_cancel`/`Terminal(Cancelled)` land the
  cancel-token subset now (`cancel_accepted_terminal_cancelled`).
- The RPC frame is self-delimiting via its `payload_len`; a channel sample is a
  fixed `sample_max` slot, so decode reads exactly header + payload and ignores
  slot padding.
- Replay E2E and the fixture spec landed in M15W4 as the prerequisite; M16W1
  re-runs the fixture as gate M16W4 evidence and archives the metrics.
