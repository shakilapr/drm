## Notes

- No architecture divergence: the slice implements pinned invariants
  (observability-plane I-OB1/I-OB3/I-OB5/I-OB6, rpc-actions
  I-RPC1/I-RPC2/I-RPC3/I-RPC6/I-RPC7); no ADR.
- Introspection tools stay non-publishing observers: each owns its reserved
  diagnostic control record and releases every borrow within the bounded copy
  window, so the payload pool remains exhaustible while a tool runs (`I-OB5`,
  `REQ-OPS-003`).
- `rpc_capacity_busy_gap_forward` adds the `rpc_capacity` cell of the rpc-actions
  test matrix: a full client correlation table returns `RpcError::Busy`; a full
  server operation table consumes nothing and the retained request is forwarded
  and served once a slot frees (`publish ≠ accepted`, `I-RPC6`/`I-RPC7`).
- MCU regression wiring: the host parity self-test and the zero-forbidden-heap
  symbol audit are now blocking on every PR/push (`ci.yml` `mcu` job); the 2 h
  target soak remains deferred to the `mcu-cross` hardware lane (handover
  deferral policy).
- Carry-over: Phase 32 gate assembly and Studio protocol doc ⇒ M17W2 (E4).
