## SPIKE — Gate B falsification review (E4, Day 5)

Per `I-Q1`..`I-Q16`, likely falsifiers ranked by likelihood × blast radius. Each
feeds the M21 spike plan; none blocks Gate B (each is currently evidenced by a
passing named test at the tested granularity).

| Rank | Falsifier | Likelihood × blast | Why it could falsify | M21 probe |
|---|---|---|---|---|
| 1 | **Multi-edge compiled-plan composition order** (fold order vs textbook `SE(3)` collapse, rotation-sensitive) | high × high | the `compile_plan` fold composes path segments in path order; existing multi-edge fixtures are translation-only (translations commute), so a rotation across two edges could expose an order/ inversion divergence between static and dynamic segments | add rotated 2-edge oracle fixtures; decide fold convention (ADR if divergent) |
| 2 | **Coherent `latest` under asynchronous edge rates / update races** | med × high | `t* = min_i(t_newest,i)` uses the retained ring head; a slot-only input newer than `t*` must not silently mix freshest values | randomized async-rate race harness vs single-instant oracle |
| 3 | **Reparenting race windows** | med × high | plan-version install and forest swap are single-writer today; a multi-reader window could observe a pre/post mix | concurrent-reader reparent harness once the engine permits shared reads |
| 4 | **Cache aging without a version change** | med × med | geometry reuse must never re-derive an all-clear; staleness/uncertainty stay per-query | long-wall-clock aging property over freshness contracts |
| 5 | **Interpolation over micro-discontinuities** | med × med | a jump smaller than the sample gap but above the physical threshold must still refuse interpolation | sub-gap discontinuity fixtures in the oracle |
| 6 | **Generational handle reuse (ABA)** | low × high | delete/reuse bumps the generation, but `u32` wraparound or a forged handle must never alias | wrap-boundary fixtures; exhaustion path |
| 7 | **Overlay walk depth under chained reparent** | low × med | repeated reparent can deepen an overlay chain beyond `max_overlay_depth`; the walk must refuse, never grow | chained-reparent fixtures |

## Notes

- No architecture divergence: the overlay-plan path implements the pre-existing
  [spatial-queries.md](../algorithms/spatial/spatial-queries.md) §Protocols plan
  lifecycle step 3 and [spatial-core.md](../algorithms/spatial/spatial-core.md)
  §Dual Hierarchy (bounded walk ≤ `max_overlay_depth`, cached under
  `topology_generation`). No ADR.
- **Composition-order review (carry-over from [m20w2.md](m20w2.md))**: E1/E2
  reviewed the multi-edge fold order. The implementation follows the
  [spatial-queries.md](../algorithms/spatial/spatial-queries.md) `compile_plan`
  pseudocode exactly (path-order postfix fold with the shared `execute_steps`
  executor), so implementation and algorithm doc agree — no divergence and thus
  no ADR. The rotation-sensitive multi-edge case is unresolved because the
  accepted fixtures are translation-only there; it is recorded as falsifier #1
  for M21 (new rotated oracle fixtures + a convention decision, with an ADR if a
  change is required).
- **`predict` estimated twist**: `predict` integrates an explicitly declared
  body-frame twist (`set_predict_twist`); adjoint-based twist-frame conversion
  and estimated-twist derivation remain open and are folded into the M21 spike
  plan with falsifier #1. The accepted `I-Q5` oracle (screw motion) does not
  require them.
- **Slot coherence (`I-Q14`)**: `spatial_slot_coherence` seeds a published
  sample before the readers start; an unwritten slot is the distinct empty state
  (version `0`, uninitialized payload), not a dual-epoch published sample. The
  seqlock reader was hardened with an `Acquire` fence between the field loads and
  the version re-check so a `Relaxed` field load can never be reordered past it
  on a weakly-ordered target (ARM64); `spatial_slot_model` enumerates every
  interleaving and confirms no accepted snapshot is torn.
- Regression permanence (AGENTS #14): the M19/M20 spatial suites and the new
  M20W4 `history`, `slot`, `overlay`, and `query_zero_alloc` tests become
  blocking gates.
