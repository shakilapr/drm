## Notes

- **Float determinism (E1-T3)**: the banding strategy is a combined
  absolute + relative band (`abs = 1e-12`, `rel = 1e-9`) rather than a single
  relative or ULP-scaled tolerance. Rationale: it covers near-zero coordinates
  (absolute floor) and large magnitudes (relative term) with one rule, and it is
  a real gate (≥3 orders of magnitude below a meaningful geometry error). This is
  the final-gate evidence rule; MCU/host parity uses the same rule.
- **No architecture divergence**: the reference suite implements the existing
  §Test Matrices; `REQ-SPATIAL-053` states the comparison rule already implicit
  in the MCU host-parity suite. No ADR.
- Regression permanence (AGENTS #14): all M19–M21 spatial suites plus the new
  `float_determinism` and `soak_regression` tests become blocking gates.
- Carry-over: final Phase 33 gate at M22W2 (chair E1, presenter E2).
