## Perf invariants (I-QAL5)

Bench commands are CI-required (`.github/workflows/ci.yml` `bench` job). Each
bench asserts zero allocation on the steady-state path and a bounded-time p99
ceiling; a violation aborts with a non-zero exit. Measured on the pinned
x86-64 host with `--warm-up-time 0.1 --measurement-time 0.2 --sample-size 10`.

| Bench | Path | p99 | Budget |
|---|---|---|---|
| `invariant_publish_latest` | core publish + `latest` | 200 ns | 50 µs |
| `publish_queue_full` | core exhaustion/backpressure | 40 ns | 50 µs |
| `invariant_ring` | ring commit + lookup | 50 ns | 50 µs |
| `invariant_codec_roundtrip` | canon-codec primitive + validate | 40 ns | 5 µs |
| `invariant_lane_loopback` | router lane send + service | 40 ns | 20 µs |
| `serial_frame_roundtrip` | serial encode + decode | 1.19 µs | 20 µs |
| `udp_loopback` | UDP datagram round trip | 3.04 µs | 500 µs |

Zero-allocation assertions cover the publish/read, ring, pool, borrow, lane, and
codec blocks (counting `GlobalAlloc`). `publish_queue_full` also asserts the
`Reject` topic returns `QueueFull` without blocking and without a pool drop
(REQ-CORE-040).
