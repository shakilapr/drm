## M13W3 full conformance port (criterion 1)

lifecycle, toolchain, router, and bindings families. Each row is green on the
Windows runner or scheduled with a `PORT_BOARD` entry (owner + target week +
gate-risk note); `board_complete()` fails the manifest if any scheduled row is
untracked (`PORT_GAPS_CLOSED`). `cargo xtask test --cross-os --full` executes the
